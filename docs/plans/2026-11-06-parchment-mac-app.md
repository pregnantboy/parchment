# Parchment Mac app: implementation plan

Status: in progress. Design direction: **"Ink"** (direction B on the mockup canvas).
Ink effects (animated ink, candlelight, etc.) are explicitly **out of scope** for this plan.

## Product decisions (settled with the user)

- Native SwiftUI + AppKit app, **macOS 26+**, built with **Xcode 27 / Swift 6.4**, project generated by **XcodeGen**.
- **Live inline styling** (Bear/iA style): one pane, Markdown symbols stay visible but faint.
- Document-based: open/save `.md` files, multiple windows. No folder sidebar, no library, no export in v1.
- Font: **SF Pro** (system) for text, **SF Mono** for code. Palette: warm paper, Ink values below.
- Extras in v1: light + dark (follows macOS), focus mode, typewriter mode, word count + reading time,
  GFM extras (fenced code with highlighting, tables as aligned monospace text, task lists),
  inline images (local + web), format shortcuts, smart lists, auto-pair, outline popover.
- App Sandbox **off** (so relative image paths next to the document load). Hardened runtime on.

## What already exists

`Packages/ParchmentCore` (Foundation-free, 63 passing tests, builds on Linux with `/opt/swift/usr/bin/swift`):

- `SpanKind`: syntax, strong, emphasis, strikethrough, code, linkText(destination), linkDestination(destination), listMarker, quoteMarker, taskBox(isChecked), completedTask, tableHeader, codeToken(CodeTokenKind)
- `LineDiff.changedLines(old:oldLines:new:newLines:) -> Range<Int>` (indices into new lines to restyle)
- `MarkdownEditing`: `newline`, `indentListItems`, `outdentListItems`, `toggleWrap(_:in:selection:)`, `setHeading(level:in:selection:)`, `insertLink`, `toggleTask`, `toggleTaskBox(at:in:selection:)`

- `TextEdit { range, replacement, selection }`, `DocumentStats(counting:)` (`words`, `readingMinutes`), `OutlineHeading.headings(in:text:)`

All edit commands return `TextEdit?` (nil = let NSTextView do its default). Offsets are UTF-16, so
`NSRange(location: r.location, length: r.length)` converts directly.

Type (at default body size 18; everything scales with the user's text size, 12...28, ⌘+/⌘−):

| Role | Size | Weight / notes |
|---|---|---|
| H1 | 48 (×2.667) | heavy (`.heavy`), kern −0.035em |
| H2 | 28 (×1.556) | bold, kern −0.02em |
| H3 | 21 (×1.167) | bold |
| H4–H6 | 18 (×1.0) | semibold |
| Body | 18 | regular, line height ≈1.62 (lineSpacing ≈ 0.62×size − font leading; use `lineHeightMultiple` 1.0 + `lineSpacing` = round(size×0.5)) |
| Code | 0.8×body (14.5) | SF Mono regular |
| Paragraph spacing | 1.0×body after paragraphs; headings: before H1 0, H2 2.2×, H3 1.6×; after 0.75× |

Layout: text **measure** = `fontSize × 36.7` (660pt at 18). A **hanging gutter** of `fontSize × 3.55` (64pt at 18)
sits to the left of the measure. The text container covers gutter + measure; centered in the window via
`textContainerInset.width`. Top inset 28pt (normal) or half the visible height (typewriter mode).

Hanging syntax (the Ink signature): for headings, list items, tasks, and quotes, the block prefix
(`## `, `- `, `1. `, `> `) is placed **inside the gutter** so the text edge stays straight:
`firstLineHeadIndent = gutter − width(prefix)`, `headIndent = gutter`. Heading `#`s use the accent color and
bold weight; list markers and `>` use `marker`. All other paragraphs: `firstLineHeadIndent = headIndent = gutter`.
Code blocks: background extends 22pt beyond the measure on both sides, radius 12, fence lines in `codeFence`.
Quotes: 4pt accent bar at the gutter edge (x = gutter), text indented 22pt, 1.28× size, semibold.
Tasks: `[ ]`/`[x]` glyphs are drawn transparent and replaced by an 18pt circle (2pt ink stroke; checked = accent
fill + white check). Completed task text: muted + strikethrough. Rules: faint `---` then a 1pt line to the measure edge.
Images: drawn below their line (paragraph spacing reserves the height), max width = measure + 80, max height 520,
radius 12, never upscaled.

Window chrome: hidden title text (`.toolbar(removing: .title)` is fine, document name still in the Window menu
and proxy), one toolbar button "Outline" (`list.bullet.indent`), toolbar background hidden, paper everywhere.
**Progress line**: 3pt accent bar along the top edge of the window content, width = scroll fraction.
**Status pill**: bottom center, ink background, paper text, 12pt: "1,204 words" (semibold) + "6 min read"
(70% opacity); shows "42 of 1,204 words" when text is selected; fades out while typing and back after 1.2s idle
(respects Reduce Motion: no fade, just hide/show).

### Text system (TextKit 1, built explicitly)

`NSTextStorage` → `MarkdownLayoutManager` (subclass of `NSLayoutManager`) → `NSTextContainer` → `ParchmentTextView`
(subclass of `NSTextView`, created with `init(frame:textContainer:)`). **The text view must keep a strong reference to
the text storage** (TextKit 1 ownership gotcha). Never touch `textView.textLayoutManager`.

Text view config: `isRichText = false`, `allowsUndo = true`, `usesFindBar = true`, `isIncrementalSearchingEnabled = true`,
`isContinuousSpellCheckingEnabled = true`, all automatic substitutions (quotes, dashes, text replacement, link detection,
data detection) off, `smartInsertDeleteEnabled = false`, `importsGraphics = false`, `drawsBackground = true` with paper,
`insertionPointColor = accent`, `selectedTextAttributes = [.backgroundColor: selection]`.

### Undo and saving

`MarkdownDocument` is a **`ReferenceFileDocument`** (class), so SwiftUI does *not* register its own undo actions.
The text view registers undo in the document's undo manager: `EditorCoordinator` implements
`undoManager(for:)` returning `context.environment.undoManager` captured in `makeNSView/updateNSView`. Every text
change (typing, undo/redo, programmatic edits) updates `document.text` from `textDidChange`. SwiftUI marks the
document dirty from the undo registrations. Programmatic edits go through:

```swift
func apply(_ edit: TextEdit)  // ParchmentTextView
// shouldChangeText(in:replacementString:) → textStorage.replaceCharacters → didChangeText() → setSelectedRange
```

### Styling pipeline

`textDidChange` (delegate, fires for typing AND undo) → `MarkdownStyler.restyle(textStorage, fullRestyle: false)`:
parse whole document (≈3 ms per 300 KB in release), `LineDiff` against the previous parse, then inside
`beginEditing/endEditing` reset + apply attributes only for changed lines (`fullRange`). Full restyle on load,
text-size change, width change (images), and image load. After restyling, reset `typingAttributes` to base body.

## Shared interfaces (every workstream must match these exactly)

```swift
// Theme/Palette.swift
nonisolated enum Palette {           // computed static vars, dynamic NSColor(name:dynamicProvider:)
    static var paper: NSColor { get }; static var ink: NSColor { get }; static var muted: NSColor { get }
    static var marker: NSColor { get }; static var accent: NSColor { get }; static var dimmed: NSColor { get }
    static var codeBackground: NSColor { get }; static var codeText: NSColor { get }; static var codeFence: NSColor { get }
    static var inlineCodeBackground: NSColor { get }; static var rule: NSColor { get }; static var selection: NSColor { get }
    static func color(for token: CodeTokenKind) -> NSColor
}
extension Color { static var parchmentPaper/parchmentInk/parchmentMuted/parchmentAccent: Color }   // Color(nsColor:)

// Theme/EditorMetrics.swift
nonisolated struct EditorMetrics: Equatable, Sendable {
    static let defaultFontSize = 18.0; static let fontSizeRange = 12.0...28.0
    init(fontSize: Double)
    var fontSize: Double; var measure: Double; var gutter: Double; var codeFontSize: Double
    var lineSpacing: Double; var paragraphSpacing: Double; var topInset: Double
    func headingSize(level: Int) -> Double
    func headingSpacingBefore(level: Int) -> Double
}

// Theme/FontBook.swift
nonisolated final class FontBook: @unchecked Sendable {   // NSLock-protected cache
    static let shared: FontBook
    func text(size: Double, weight: NSFont.Weight = .regular, italic: Bool = false) -> NSFont
    func mono(size: Double, weight: NSFont.Weight = .regular, italic: Bool = false) -> NSFont
    func adding(bold: Bool, italic: Bool, to font: NSFont) -> NSFont   // for strong/emphasis spans
}

// Theme/ParchmentAttribute.swift
nonisolated extension NSAttributedString.Key {
    static let parchmentBlock: NSAttributedString.Key   // value: NSNumber(BlockDecoration.rawValue), on a line's fullRange
    static let parchmentTaskBox: NSAttributedString.Key // value: NSNumber(Bool isChecked), on the 3-char `[ ]`
    static let parchmentImage: NSAttributedString.Key   // value: NSImage, on the image line's range
    static let parchmentLink: NSAttributedString.Key    // value: String URL, on link text + destination
    static let parchmentRule: NSAttributedString.Key    // value: NSNumber(true), on a rule line
}

// Theme/BlockDecoration.swift
nonisolated struct BlockDecoration: OptionSet, Sendable {
    let rawValue: Int
    static let code, quote, isFirst, isLast   // code|quote plus position flags from MarkdownLine.blockPosition
}

// Editor/EditorCommand.swift
enum EditorCommand: Equatable {
    case bold, italic, strikethrough, inlineCode, link, heading(Int), task, indent, outdent
}

// Editor/ParchmentTextView.swift (public surface used by Window/)
final class ParchmentTextView: NSTextView {
    var metrics: EditorMetrics          // setting it restyles fully and relayouts
    var isFocusMode: Bool               // dims all but the current paragraph via temporary attributes
    var isTypewriterMode: Bool          // keeps the caret line vertically centered
    func perform(_ command: EditorCommand)
    func reveal(_ range: TextRange)     // select start of range, scroll it to the upper third
    func apply(_ edit: TextEdit)
}

// Editor/EditorView.swift
struct EditorView: NSViewRepresentable {
    let document: MarkdownDocument
    let fileURL: URL?
    let controller: EditorController
    let fontSize: Double
    let isFocusMode: Bool
    let isTypewriterMode: Bool
}

// Window/EditorController.swift  (one per window, owned as @State in DocumentWindowView)
@Observable final class EditorController {
    @ObservationIgnored weak var textView: ParchmentTextView?
    private(set) var stats: DocumentStats = .empty
    private(set) var selectionStats: DocumentStats?        // nil when nothing selected
    private(set) var headings: [OutlineHeading] = []
    private(set) var scrollProgress: Double = 0            // 0...1
    private(set) var isTyping = false
    var isShowingOutline = false
    // Called by the editor engine:
    func textDidChange(_ text: MarkdownText, lines: [MarkdownLine])   // debounces stats/outline ~150 ms, sets isTyping
    func selectionDidChange(selectedText: String)                     // empty string = no selection
    func scrollDidChange(progress: Double)
    // Called by menus and views:
    func perform(_ command: EditorCommand)                            // forwards to textView
    func reveal(_ heading: OutlineHeading)
}

// App/FocusedValues+Editor.swift
extension FocusedValues { @Entry var editorController: EditorController? }

// App/PreferenceKey.swift
enum PreferenceKey { static let fontSize = "fontSize"; static let focusMode = "focusMode"; static let typewriterMode = "typewriterMode" }

// Document/MarkdownDocument.swift
nonisolated final class MarkdownDocument: ReferenceFileDocument, @unchecked Sendable {
    static var readableContentTypes: [UTType] { [.markdownText, .plainText] }
    var text: String { get set }      // NSLock-protected
    init(text: String = "")
}
// Document/UTType+Markdown.swift: nonisolated extension UTType { static let markdownText = UTType(importedAs: "net.daringfireball.markdown") }
```

### Concurrency rules (the main compile risk; nobody can compile AppKit code in this sandbox)

- App target: Swift 6 mode, `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`, `SWIFT_APPROACHABLE_CONCURRENCY = YES`.
- `NSLayoutManager` is not main-actor isolated, so `MarkdownLayoutManager` and its overrides are nonisolated.
  Its drawing code may only use `nonisolated` things: `Palette`, `BlockDecoration`, attribute keys, `FontBook`,
  and data read from `textStorage` attributes. No `ImageStore`, no controller access.
- Types used from the layout manager or from the document's background save are marked `nonisolated`.
- No `DispatchQueue`; use `Task`, `Task.sleep(for:)`. No force unwraps. No `print` for user-facing errors.
- `ImageStore` is `@MainActor`, loads with `URLSession.shared.data(from:)` (works for `file://` too) in a `Task`,
  caches `NSImage` by URL, calls back so the styler restyles image lines.

### WS-B Theme (Sonnet)

### WS-C Editor engine (Opus)
`Parchment/Editor/*.swift`. Text system setup, styling pipeline, hanging gutter paragraph styles, layout-manager
drawing (code block backgrounds with first/last rounding using line-fragment rects vs used rects, quote bar, rule line,
task circles, images), clicks (task circle toggles via `MarkdownEditing.toggleTaskBox`; ⌘-click opens
`parchmentLink`), key handling in `textView(_:doCommandBy:)` (insertNewline → `MarkdownEditing.newline`,
insertTab/insertBacktab → indent/outdent, deleteBackward → `AutoPair.deleteBackward`), `insertText` override for
`AutoPair.insert` (skip when `hasMarkedText()`), focus mode (temporary `.foregroundColor` = dimmed over everything
except the current paragraph: contiguous non-blank lines around the caret), typewriter scrolling, centering the
container on resize, reporting to `EditorController` (text, selection, scroll progress via the clip view's
bounds-did-change notification).
